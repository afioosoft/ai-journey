# رحلة الذكاء الاصطناعي

تطبيق دروس تفاعلية للأطفال عن الذكاء الاصطناعي (٨ دروس، مستويان: ٦ سنوات و١٠ سنوات).
يعمل بدون إنترنت بعد فتحه أول مرة، ويُثبَّت على الشاشة الرئيسية في iPad وAndroid والحاسوب.

لا حسابات ولا إعلانات. النجوم والتقدّم محفوظة على الجهاز فقط.

اللغات: العربية (الأصل) والإنجليزية، ويمكن إضافة الألمانية والفرنسية. زرّ 🌐 في أعلى الشاشة يغيّر اللغة. طريقة الترجمة في [i18n/README.md](i18n/README.md).
